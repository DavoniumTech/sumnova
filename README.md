SumNova

Learn Faster. Understand Better.

SumNova is an AI-powered study assistant developed by Davonium Technologies. It helps students, researchers, and professionals quickly understand information by generating clear, accurate summaries.

Features

- 📚 Exam Summary
- 📝 Assignment Summary
- 📖 Research Paper Summary
- 💼 Business Meeting Summary
- 📄 PDF Summary (Coming Soon)
- 🌐 Website Summary (Coming Soon)
- 🕒 Summary History
- 🔒 Secure Firebase Authentication
- 📱 Installable Progressive Web App (PWA)

Built With

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Cloud Firestore
- AI Summarization

Vision

Our mission is to help students and professionals learn faster, understand better, and save valuable time using artificial intelligence.
